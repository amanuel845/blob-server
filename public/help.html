💬 Help & Support

Frequently Asked Questions

❓ How do I unlock the app?

Enter the password you received (or the one you set) in the unlock modal. Your encrypted API key is stored locally and decrypted in your browser – no data is sent to any server.

❓ What file types are supported?

All file types are accepted. However, the app is optimised for JSON files – they are displayed with a code viewer and can be renamed with a prefix. Other files (images, videos, etc.) are uploaded and stored, but cannot be previewed in the code viewer.

❓ Why do some files have a random suffix?

When a file is uploaded directly from the browser (presigned URL), Vercel Blob automatically adds a random suffix to prevent overwrites. The app strips this suffix for display, so you only see the clean filename.

❓ How can I delete multiple files at once?

Go to the Files tab, select the checkboxes for the files you want to delete, then click the Delete Selected button. You will be asked for confirmation before deletion.

❓ What does the “Lock” button do?

It clears your decrypted API key from memory and localStorage, forcing you to unlock again. This is useful if you step away from your device.

❓ Can I cancel an upload?

Yes – while an upload is in progress, a Cancel button appears in the progress bar. Click it to stop the upload immediately.

❓ Where can I change the upload category?

In the TikTok tab, you’ll find a Category input. Change it to any folder path you like (e.g., videos/summer). The change is saved automatically.

📞 Contact Support

If you encounter any issues or have questions not covered here, please reach out via email to support@tiktok-uploader.example.

We aim to respond within 24 hours.

🛠️ Troubleshooting

  • Unlock fails: Make sure your password is correct. If you've lost it, contact support to reset your encrypted key.
  • Upload hangs: Check your internet connection. If the problem persists, refresh the page and try again.
  • Files not showing: Click the Refresh button in the toolbar to reload the list from the server.
  • Config changes not applied: After saving a config value, the UI updates immediately. If a value seems stuck, try refreshing the page.
